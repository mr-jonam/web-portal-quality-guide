# First result: Web Portal Quality Guide

This is a fictional, synthetic reading exercise. The brief below is an editorial illustration, not a captured tool result or evidence from a customer system.

## Start with one situation

A fictional portal submits an application to another platform. The team has described submission but has not agreed how the user learns the final outcome or which role owns the handoff.

## Keep the input small

```text
Journey: application submission.
Known: the initial user action.
Uncertain: final outcome, role differences and handoff ownership.
```

## A useful discussion question

> What outcome should the user see after the handoff, and who owns acceptance?

Read the journey, identity and accessibility discussion. Keep unknown accessibility and role evidence explicitly unknown.

## Try it yourself

1. Read the [decision guide](../GUIDE.md).
2. Write one known fact and one unknown on your own private notes.
3. If useful, open the mini tool using the [local preview instructions](../README.md#start-here) and represent the same uncertainty with its available choices.
4. Keep one question and the role that should answer it. The tool wording may differ from this illustration.
