Privacy & limitations

A local tool for an initial conversation.

What the website processes

The mini tool processes only the answers or numeric assumptions entered into the current page. Its own code sends no network requests, uses no cookies, telemetry, advertising scripts, local storage or session storage, and calls no AI service. Copy and download actions are local and user initiated. The site does not save the form state; browser history or form restoration may still preserve values according to your browser settings.

Hosting and external links

The eventual hosting provider can process normal connection information such as IP addresses and request logs. A hosting-specific privacy notice must be reviewed before publication. Following an official reference or an approved contact link takes you to a third-party service with its own terms. No assessment answers are added to those URLs.

Limits of the material

This is general editorial orientation based on cited public references. It is not a system assessment, implementation plan, test execution, maturity benchmark, compliance determination, security audit, accessibility certification or release approval. No supplied answer is independently verified.

Optional assistant skill

Each repository includes an optional SKILL.md for a separately selected assistant. It provides discussion guidance and no connector, API key or execution harness. The assistant’s own data processing is separate from this website; review its configuration and use only non-sensitive category-level information.

Rights and identity

The local preparation retains provisional private-development rights until the legal holder and final component licences are approved. Product names belong to their respective owners. No endorsement or vendor relationship is implied.
